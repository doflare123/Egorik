# Изменения

## v0.1 / 0.1.0

Первый предварительный релиз для Windows x64.

- Текстовые команды, пользовательские сценарии и настройки приложений и сайтов.
- Локальное распознавание Vosk и нейроголос Piper/Sherpa-ONNX;
  модели устанавливаются пользователем из настроек.
- Опциональный ИИ-планировщик с локальной проверкой разрешённых инструментов.
- Интеграции Steam, Яндекс Музыки, Word и Excel; JavaScript-плагины API v1.
- Работа в системном tray.
- Portable ZIP с `Egorik.exe`, .NET и нативными библиотеками.

Распакуйте архив полностью и запустите `Egorik.exe`. Устанавливать .NET отдельно
не требуется. DLL и каталог `plugins` должны оставаться рядом с приложением.

Ограничения: только Windows x64; установщика, цифровой подписи и автоматического
обновления пока нет. Голосовые модели не включены в архив. Для интеграций нужны
соответствующие установленные приложения и настройки пользователя.
