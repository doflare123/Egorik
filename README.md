# Egorik

Настольный полу-ИИ ассистент для Windows с платформенными контрактами для будущей
поддержки других ОС. Проект строится по принципу
«детерминированные команды сначала, ИИ-планировщик только как безопасный fallback».

## Текущий MVP

- первый запуск с выбором имени ассистента;
- текстовый контур команд для быстрой проверки логики;
- открытие настроенных приложений и сайтов;
- интернет-поиск через Yandex, Google или DuckDuckGo;
- безопасный арифметический калькулятор;
- локальные дата и время;
- Windows media keys: пауза, треки и громкость;
- типизированные интеграции приложений: браузер по умолчанию, Steam,
  Яндекс Музыка, Microsoft Word и Microsoft Excel;
- запуск установленной игры Steam по имени из локальных библиотек, включая
  безопасное сопоставление русской формы вроде «доту» с `Dota 2`;
- создание нового документа Word в каталоге данных Egorik;
- локальный поиск по явно разрешённым пользователем книгам `.xlsx`;
- кодовые JavaScript-плагины API v1 в ограниченном интерпретаторе без CLR,
  shell и прямого доступа к системе;
- опциональный плагин «Пик героя Dota 2» со стандартными и сленговыми
  русскими названиями героев;
- пользовательские сценарии из последовательности базовых команд;
- редактирование псевдонимов приложений и сайтов;
- OpenAI-compatible ИИ-планировщик для команд, которые не распознаны базовым
  маршрутизатором;
- локальная русская голосовая активация через Vosk с индикатором реального
  аудиопотока и промежуточного распознавания;
- полноэкранная wake-анимация по краям основного монитора после обращения к
  ассистенту;
- локальный нейроголос Piper через Sherpa-ONNX с системным голосом Windows
  в качестве резервного;
- фоновая работа из системного tray: крестик скрывает окно, а голосовой ввод и
  озвучка продолжают работать;
- контракты для смены wake word, STT, TTS, AI и плагинов;
- JSON-настройки в `%LocalAppData%\Egorik`.

Русская модель Vosk весит около 45 МБ и загружается по явной кнопке в настройках.
После загрузки голосовая активация включается автоматически. Можно произнести имя
вместе с командой либо сначала имя, а затем команду в течение восьми секунд.
Интерфейс показывает уровень входного сигнала и распознаваемый текст, поэтому
состояние микрофона можно проверить без догадок.

После распознавания имени по краям основного экрана появляется цветная анимация.
Она не перехватывает фокус и клики и исчезает, когда команда принята в обработку.
Крестик главного окна скрывает приложение в tray. Для полного завершения нужно
выбрать пункт «Полный выход» в меню значка Egorik.

Wake word сопоставляется фонетически: типичные результаты STT вроде «игорек»,
«игор рек» или «егор рек» принимаются как «Егорик». Нечёткое сравнение применяется
только к имени в начале фразы, а не к самой команде.

Нейроголос Denis весит около 81 МБ и также устанавливается отдельной кнопкой.
После установки синтез выполняется локально. Если модель или нативный движок
недоступны, приложение автоматически использует системный TTS Windows.

## ИИ-планировщик

В настройках можно включить любой API с OpenAI-compatible методом
`POST /chat/completions`: OpenAI, OpenRouter, LM Studio, Ollama или другой
совместимый сервер. Нужно указать полный endpoint, имя модели и, если провайдер
его требует, API-ключ.

По умолчанию:

```text
Endpoint: https://api.openai.com/v1/chat/completions
Model:    gpt-4o-mini
```

Для локального сервера разрешён `http://localhost`, для внешнего — только HTTPS.
Ключ не записывается в `settings.json`: на Windows он шифруется DPAPI для текущего
пользователя. Вместо сохранённого ключа можно задать переменную окружения
`EGORIK_AI_API_KEY`.

Модель не выполняет действия напрямую. API видит только обязательную функцию
`submit_plan`, которая возвращает упорядоченный список шагов. Перед выполнением
приложение повторно проверяет:

- не больше восьми шагов;
- ID каждого инструмента по локальному allowlist;
- уровень риска инструмента;
- точный набор обязательных аргументов;
- максимальную длину и допустимые значения аргументов.

Сейчас ИИ доступны только открытие приложений и сайтов из пользовательских
списков, интернет-поиск, низкорисковые действия зарегистрированных интеграций,
поиск в явно разрешённых книгах Excel, медиа, калькулятор, дата/время, разделы
интерфейса и безопасный текстовый ответ. Путь книги Excel модель не видит и не
выбирает: она может вернуть только псевдоним из локального allowlist.

Создание заметки Word является только детерминированной базовой командой и не
публикуется ИИ. Произвольных URL, путей, процессов, записи или удаления файлов,
PowerShell и shell-команд в каталоге инструментов нет.

## Интеграции приложений

Основа взаимодействия с программами находится в `Egorik.Core.Applications`.
Каждый адаптер регистрирует стабильный ID приложения и конечный каталог действий
с точными параметрами, максимальной длиной, риском и отдельным флагом доступности
для ИИ. `ApplicationActionRegistry` повторно проверяет приложение, действие,
риск, обязательные и лишние аргументы до любого побочного эффекта.

Подключённые адаптеры:

- браузер по умолчанию — открыть стартовую страницу или выполнить поиск;
- Steam — открыть клиент/библиотеку, найти игру в магазине, найти установленную
  игру в локальных `appmanifest` и запустить только через числовой App ID;
- Яндекс Музыка — найти и открыть установленный `Яндекс Музыка.exe`, выполнить
  поиск, включить Мою волну и адресно управлять её медиасессией;
- Microsoft Word — открыть программу или по явной базовой команде создать новый
  `.docx` в `%LocalAppData%\Egorik\documents` без перезаписи существующих файлов;
- Microsoft Excel — открыть программу или искать значения в выбранной книге
  `.xlsx` в режиме чтения. Разрешённые книги задаются в настройках в формате
  `имя=полный путь`.

Универсальная отправка кликов, клавиш и текста в активное окно намеренно не
используется: она не позволяет проверить цель действия. Новые программы
подключаются отдельными узкими адаптерами. Подробный контракт и порядок
расширения описаны в [документации интеграций](docs/application-integrations.md).

Плагины загружаются как JavaScript-пакеты из встроенного каталога или
`%LocalAppData%\Egorik\plugins`. Код может выполнять собственные условия,
циклы и обработку данных, а системное действие запрашивает через разрешённую
локальную capability. CLR, DLL, shell, сеть, файловая система и service provider
плагину недоступны. Формат описан в
[документации плагинов](docs/plugins.md).

## Структура

```text
src/Egorik.Core            команды, сценарии, политики и контракты
src/Egorik.Infrastructure  хранение, базовые команды и desktop-адаптеры
src/Egorik.App             Avalonia UI
tests/Egorik.App.Tests     тесты состояния голосового интерфейса
tests/Egorik.Core.Tests    тесты маршрутизации и безопасных вычислений
```

## Запуск

Требуется .NET 10 SDK.

```powershell
dotnet restore Egorik.slnx
dotnet test Egorik.slnx
dotnet run --project src/Egorik.App/Egorik.App.csproj
```

## Правило безопасности

ИИ и плагины не получают прямой shell-доступ. Системный промпт и строгая
JSON-схема уменьшают число ошибочных планов, но границей безопасности считается
только локальный allowlist и повторная проверка перед выполнением.
