# Egorik

Настольный полу-ИИ ассистент для Windows с платформенными контрактами для будущей
поддержки других ОС. Проект строится по принципу
«детерминированные команды сначала, ИИ-планировщик только как безопасный fallback».

## Установка v0.1

В [GitHub Releases](https://github.com/doflare123/Egorik/releases) выберите
релиз v0.1, когда он будет опубликован, и скачайте `Egorik-0.1.0-win-x64.zip`.
Распакуйте весь архив и запустите `Egorik.exe`. Требуется Windows 10 1809+
или Windows 11, x64; отдельная установка .NET не нужна.
DLL и папка `plugins` должны оставаться рядом с exe.

Голосовые модели скачиваются отдельными кнопками в настройках. Пользовательские
данные сохраняются в `%LocalAppData%\Egorik`, отдельно от папки программы.
Это предварительная portable-версия без установщика и цифровой подписи.

Сборка архива: `./scripts/Publish-Release.ps1` (Windows и .NET 10 SDK).
Подробности — [подготовка релиза](docs/releases.md), изменения —
[CHANGELOG.md](CHANGELOG.md).

## Текущий MVP

Вкладка **«Справочник»** показывает встроенные команды и описания установленных
плагинов с примерами и состоянием доступности. Кнопка «Показать возможности» и
команда «что ты умеешь» открывают эту вкладку; длинный список вслух не читается.

В настройках ассистента доступны:

- **«Короткий ответ»** — по умолчанию выключен. При включении результат любой
  команды озвучивается только как «Задача выполнена» или «Задача не выполнена».
  Режим имеет приоритет над подробной озвучкой ошибок; полный ответ остаётся
  в истории и статусе. Для озвучивания должна быть включена настройка
  «Озвучивать ответы». Нажмите «Сохранить настройки», чтобы сохранить выбор.
- **«Подробная информация о неудаче»** — по умолчанию выключена. Ошибки
  озвучиваются кратко (например, «API ИИ недоступен»); при включении зачитываются
  подробности. Полный текст остаётся в истории и статусе интерфейса.
- **«Запускать вместе с Windows в tray»** — по умолчанию выключена. После
  сохранения регистрируется запуск текущего `Egorik.exe --tray` при входе
  пользователя в Windows. Окно открывается по значку в tray; голосовой ввод
  работает согласно сохранённым настройкам. При переносе portable-приложения
  сохраните настройку заново из новой папки. Снятие галочки удаляет автозапуск.

При работающем распознавании слово **«отбой»** немедленно сбрасывает ожидаемую
команду и блокирует обращения на 10 секунд. Обрабатывается локально, включая
промежуточные результаты Vosk; ИИ не вызывается. Уже совершённые действия не
отменяются. Во время озвучивания микрофон по-прежнему приостановлен для защиты
от самосрабатывания, поэтому «отбой» в этот момент не распознаётся.
Посреди непрерывной речи используйте явное обращение **«слушай, Егорик»**
(или выбранное имя), затем команду. Простое упоминание имени внутри предложения
не активирует ассистента; нечёткое имя распознаётся только в начале фразы.

- первый запуск с выбором имени ассистента;
- текстовый контур команд для быстрой проверки логики;
- открытие настроенных приложений и сайтов;
- интернет-поиск через Yandex, Google или DuckDuckGo;
- безопасный арифметический калькулятор;
- локальные дата и время;
- Windows media keys: пауза, треки и громкость;
- типизированные интеграции приложений: браузер по умолчанию, Steam,
  Яндекс Музыка, Microsoft Word и Microsoft Excel;
- запуск установленной игры Steam по имени из локальных библиотек, включая
  безопасное сопоставление русской формы вроде «доту» с `Dota 2`;
- создание нового документа Word в каталоге данных Egorik;
- локальный поиск по явно разрешённым пользователем книгам `.xlsx`;
- кодовые JavaScript-плагины API v1 в ограниченном интерпретаторе без CLR,
  shell и прямого доступа к системе;
- опциональный плагин «Пик героя Dota 2» со стандартными и сленговыми
  русскими названиями героев;
- пользовательские сценарии из последовательности базовых команд;
- редактирование псевдонимов приложений и сайтов;
- OpenAI-compatible ИИ-планировщик для команд, которые не распознаны базовым
  маршрутизатором;
- локальная русская голосовая активация через Vosk с индикатором реального
  аудиопотока и промежуточного распознавания;
- полноэкранная wake-анимация по краям основного монитора после обращения к
  ассистенту;
- локальный нейроголос Piper через Sherpa-ONNX с системным голосом Windows
  в качестве резервного;
- фоновая работа из системного tray: крестик скрывает окно, а голосовой ввод и
  озвучка продолжают работать;
- контракты для смены wake word, STT, TTS, AI и плагинов;
- JSON-настройки в `%LocalAppData%\Egorik`.

Русская модель Vosk весит около 45 МБ и загружается по явной кнопке в настройках.
После загрузки голосовая активация включается автоматически. Можно произнести имя
вместе с командой либо сначала имя, а затем команду в течение восьми секунд.
Интерфейс показывает уровень входного сигнала и распознаваемый текст, поэтому
состояние микрофона можно проверить без догадок.

Завершённые фрагменты Vosk собираются в одну фразу: отправка команды ждёт
1,2 секунды без нового распознанного текста после последнего фрагмента.
Промежуточные гипотезы не исполняются. При остановке или паузе прослушивания
буфер очищается. Фраза ограничена 30 секундами и 1024 символами; при превышении
ограничений она отбрасывается целиком, без исполнения отдельных фрагментов.

Для текстового и голосового ввода поддерживаются разговорные обороты, например
«можешь открыть мне браузер, пожалуйста» и «можешь поставить на паузу».
Сначала проверяются исходные команды; разговорный вариант применяется только
если совпадения не было и только к командам низкого риска. Пользовательские
сценарии сохраняют приоритет. Ошибочные пробелы в известных глаголах открытия
и сохранённых названиях учитываются без замены букв: «от крой брау зер»,
«откройбраузер», «яндексмузыку». Неоднозначное сохранённое название не выбирается
наугад. Произвольные опечатки в глаголах команд не исправляются.

После распознавания имени по краям основного экрана появляется цветная анимация.
Она не перехватывает фокус и клики и исчезает, когда команда принята в обработку.
Крестик главного окна скрывает приложение в tray. Для полного завершения нужно
выбрать пункт «Полный выход» в меню значка Egorik.

В tray и при минимизации обновление невидимого индикатора уровня отключено;
при открытии он сразу показывает последнее состояние. Очередь этих обновлений
хранит только последнее событие. Анимация рамки работает только пока рамка видна.
Распознавание и выполнение команд в фоне продолжаются.

Для ограничения нативной памяти Vosk история декодера освобождается на первой
границе фразы после 60 секунд аудио, без повторной загрузки модели. Завершённые
фрагменты фразы сохраняются. Если непрерывный звук не даёт границы 90 секунд,
незавершённая фраза отбрасывается и декодер создаётся заново; её части не исполняются.

Wake word сопоставляется фонетически: типичные результаты STT вроде «игорек»,
«игор рек» или «егор рек» принимаются как «Егорик». Нечёткое сравнение применяется
только к имени в начале фразы, а не к самой команде.

Нейроголос Denis весит около 81 МБ и также устанавливается отдельной кнопкой.
После установки синтез выполняется локально. Если модель или нативный движок
недоступны, приложение автоматически использует системный TTS Windows.

В «Настройки → Ассистент → Микрофон» выберите устройство записи и нажмите
«Сохранить настройки». Прослушивание переключается без перезапуска приложения
и без повторной загрузки модели. «Обновить микрофоны» перечитывает список после
подключения устройства. Выбор сохраняется по Windows endpoint ID, а не номеру
в списке: порядок подключения не влияет на выбранный микрофон. Для старых
настроек используется «По умолчанию Windows». Если явно выбранное устройство
отключено, Егорик сообщает об ошибке и не переключается на другой микрофон.

## ИИ-планировщик

В настройках можно включить любой API с OpenAI-compatible методом
`POST /chat/completions`: OpenAI, OpenRouter, LM Studio, Ollama или другой
совместимый сервер. Нужно указать полный endpoint или базовый адрес API,
заканчивающийся на `/v1`, имя модели и, если провайдер его требует, API-ключ.
Для адресов `/v1` и `/v1/` приложение автоматически добавляет `/chat/completions`,
сохраняя префикс пути провайдера. Полные и нестандартные endpoint используются
как указаны. Например, `https://api.coldset.xyz/deepseekvladimir/v1` преобразуется
в `https://api.coldset.xyz/deepseekvladimir/v1/chat/completions`.
При обновлении полностью завершите старую версию через tray и запустите exe
из новой папки: уже работающий процесс не подхватывает исправления.
При ответе 405 проверьте адрес Chat Completions и разрешение POST
на стороне провайдера или прокси.

По умолчанию:

```text
Endpoint: https://api.openai.com/v1/chat/completions
Model:    gpt-4o-mini
```

Для локального сервера разрешён `http://localhost`, для внешнего — только HTTPS.
Ключ не записывается в `settings.json`: на Windows он шифруется DPAPI для текущего
пользователя. Вместо сохранённого ключа можно задать переменную окружения
`EGORIK_AI_API_KEY`.

Модель не выполняет действия напрямую. API видит только обязательную функцию
`submit_plan`, которая возвращает упорядоченный список шагов. Перед выполнением
приложение повторно проверяет:

- не больше восьми шагов;
- ID каждого инструмента по локальному allowlist;
- уровень риска инструмента;
- точный набор обязательных аргументов;
- максимальную длину и допустимые значения аргументов.

Сейчас ИИ доступны только открытие приложений и сайтов из пользовательских
списков, интернет-поиск, низкорисковые действия зарегистрированных интеграций,
поиск в явно разрешённых книгах Excel, медиа, калькулятор, текущая погода, дата/время, разделы
интерфейса и безопасный текстовый ответ. Путь книги Excel модель не видит и не
выбирает: она может вернуть только псевдоним из локального allowlist.

Создание заметки Word является только детерминированной базовой командой и не
публикуется ИИ. Произвольных URL, путей, процессов, записи или удаления файлов,
PowerShell и shell-команд в каталоге инструментов нет.

При включённом и настроенном ИИ вычисления направляются планировщику. Простая
арифметика проверяется локальным инструментом `calculator`; сложные математические
вопросы модель отвечает текстом, поэтому точность такого ответа не гарантируется.
При выключенном ИИ обычная арифметика по-прежнему работает локально. Сценарии
сохраняют приоритет, а «найди погоду» или «найди решение примера» выполняют обычный
поиск в браузере без обращения к планировщику. Решение описано
в [документе о маршрутизации вычислений](docs/decisions/2026-10-11-ai-computations.md).

Для вопросов о текущей погоде ИИ выбирает `get_weather`, который получает данные
из фиксированных HTTPS endpoint Open-Meteo. Это расчёт погодных моделей, а не
гарантия точного измерения у пользователя. Ответ содержит источник и время;
устаревшие данные, неожиданные единицы измерения и неоднозначный город отклоняются.
Город по умолчанию — Калининград; его можно изменить или очистить в настройках.
Прогноз на будущую дату этим инструментом пока не поддерживается.

## Интеграции приложений

Основа взаимодействия с программами находится в `Egorik.Core.Applications`.
Каждый адаптер регистрирует стабильный ID приложения и конечный каталог действий
с точными параметрами, максимальной длиной, риском и отдельным флагом доступности
для ИИ. `ApplicationActionRegistry` повторно проверяет приложение, действие,
риск, обязательные и лишние аргументы до любого побочного эффекта.

Подключённые адаптеры:

- браузер по умолчанию — открыть стартовую страницу или выполнить поиск;
- Steam — открыть клиент/библиотеку, найти игру в магазине, найти установленную
  игру в локальных `appmanifest` и запустить только через числовой App ID;
- Яндекс Музыка — найти и открыть установленный `Яндекс Музыка.exe`, выполнить
  поиск, включить Мою волну, адресно управлять её медиасессией и громкостью;
- Microsoft Word — открыть программу или по явной базовой команде создать новый
  `.docx` в `%LocalAppData%\Egorik\documents` без перезаписи существующих файлов;
- Microsoft Excel — открыть программу или искать значения в выбранной книге
  `.xlsx` в режиме чтения. Разрешённые книги задаются в настройках в формате
  `имя=полный путь`.

Универсальная отправка кликов, клавиш и текста в активное окно намеренно не
используется: она не позволяет проверить цель действия. Новые программы
подключаются отдельными узкими адаптерами. Подробный контракт и порядок
расширения описаны в [документации интеграций](docs/application-integrations.md).

Плагины загружаются как JavaScript-пакеты из встроенного каталога или
`%LocalAppData%\Egorik\plugins`. Код может выполнять собственные условия,
циклы и обработку данных, а системное действие запрашивает через разрешённую
локальную capability. CLR, DLL, shell, сеть, файловая система и service provider
плагину недоступны. Формат описан в
[документации плагинов](docs/plugins.md).

## Структура

```text
src/Egorik.Core            команды, сценарии, политики и контракты
src/Egorik.Infrastructure  хранение, базовые команды и desktop-адаптеры
src/Egorik.App             Avalonia UI
tests/Egorik.App.Tests     тесты состояния голосового интерфейса
tests/Egorik.Core.Tests    тесты маршрутизации и безопасных вычислений
```

## Запуск

Требуется .NET 10 SDK.

```powershell
dotnet restore Egorik.slnx
dotnet test Egorik.slnx
dotnet run --project src/Egorik.App/Egorik.App.csproj
```

## Правило безопасности

ИИ и плагины не получают прямой shell-доступ. Системный промпт и строгая
JSON-схема уменьшают число ошибочных планов, но границей безопасности считается
только локальный allowlist и повторная проверка перед выполнением.
