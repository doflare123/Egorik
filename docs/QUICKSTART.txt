Egorik v0.1 — Windows x64

1. Полностью распакуйте ZIP в отдельную папку.
2. Запустите Egorik.exe из распакованной папки.
   .NET уже включён. Оставьте DLL и каталог plugins рядом с exe.
3. Выберите имя ассистента и проверьте текстовую команду «который час».
4. Для голосового ввода скачайте модель Vosk кнопкой в настройках.
   В «Настройки → Ассистент → Микрофон» выберите нужный вход и сохраните
   настройки. Для подключённого позже микрофона нажмите «Обновить микрофоны».
   Нейроголос также устанавливается отдельной кнопкой. Нужен интернет
   только для загрузки моделей; распознавание и синтез работают локально.
5. ИИ необязателен: при необходимости настройте endpoint, модель и ключ.
   Базовый адрес, заканчивающийся на /v1, автоматически дополняется
   /chat/completions. Для старых версий укажите полный адрес метода.
   Город для текущей погоды по умолчанию — Калининград, меняется в настройках.

Платформа: Windows 10 версии 1809 или новее, x64.
Архив не содержит установщика и цифровой подписи.
Крестик скрывает окно в tray. Для завершения выберите «Полный выход».
Автозапуск: в настройках включите «Запускать вместе с Windows в tray» и сохраните.
Справочник команд доступен отдельной вкладкой, включая команды плагинов.
«Отбой» при активном микрофоне блокирует обращения на 10 секунд.
Посреди разговора обращайтесь «слушай, Егорик» (или выбранное имя).
Для озвучивания полных ошибок включите «Подробная информация о неудаче».
В tray голосовые команды продолжают работать; невидимые индикаторы и анимации
не обновляются. При открытии окна отображается последнее состояние микрофона.
Настройки, модели и журналы: %LocalAppData%\Egorik.
Для обновления завершите приложение и распакуйте новую версию в новую папку.
Пользовательские данные сохраняются отдельно; удалять их не нужно.

Исходный код и релизы: https://github.com/doflare123/Egorik
